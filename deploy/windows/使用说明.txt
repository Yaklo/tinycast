轻量级直播平台 TinyCast —— Windows 免安装体验包
=================================================

本目录里的两个 exe 都是单文件、无需安装任何运行环境（不需要 Go / Node / Docker / SRS）。
在 Windows 上直接双击即可运行。

文件说明
--------
tinycast.exe        服务端 + 前端（前端已内嵌在 exe 里），默认监听 http://127.0.0.1:8080
tinysim.exe         联调工具：用 HTTP 请求模拟 SRS 的推流/断流/观众进入离开回调
start-tinycast.cmd  双击启动服务并自动打开浏览器首页
simulate-srs.cmd    双击运行一次完整演示（推流 → 观众 → 断流保留 → 重新推流）

三分钟上手
----------
1. 双击 start-tinycast.cmd，浏览器会自动打开 http://127.0.0.1:8080 。
   控制台窗口会一直挂着，关闭窗口即停止服务（内存状态随之清空，这是设计取舍）。
2. 在首页点「创建推流配置」，随意填写用户名与房间名称，页面会生成推流令牌和 OBS 推流地址。
   这一步完全在浏览器本地完成，不会请求后端，也不会创建房间。
3. 双击 simulate-srs.cmd（或在命令行执行 tinysim.exe demo），它会按顺序模拟：
   - OBS 开始推流（on_publish）→ 首页出现房间，状态 LIVE
   - 同一身份再次推流 → 被后端拒绝（already_publishing）
   - 三个观众进入（on_play）→ 观看人数变 3
   - 一个观众离开（on_stop）→ 观看人数变 2
   - OBS 停止推流（on_unpublish）→ 房间变 GRACE，首页出现保留倒计时
   - 保留期内重新推流 → 恢复 LIVE，倒计时消失
   每一步都会回读 /api/rooms/:username，把服务端的真实状态打印出来。
4. 想让「超时释放」快点发生：在命令行里设置保留期后启动服务，例如

     set ROOM_GRACE=30s
     set JANITOR_INTERVAL=5s
     tinycast.exe -open

   然后跑 simulate-srs.cmd，等 30 秒再刷新首页，房间会自动消失。

重要限制（请先看这一节）
------------------------
* 这个包里没有 SRS，也没有真正的音视频。房间详情页的播放器会去连 WebRTC 信令，
  因为连不上会显示播放失败提示 —— 这是预期行为，不是 bug。
  推流鉴权、房间生命周期、观看人数、SSE 实时刷新这些业务逻辑全部可以正常验证。
* 要看到真实画面，需要在同一台机器（或内网）上另跑一个 SRS 6：
  把 deploy/srs/srs.conf 里的四个回调地址指向 http://127.0.0.1:8080/internal/srs/...，
  用 OBS 按首页给出的服务器地址与推流码推流即可。
* 服务不会自动加入开机启动，也不会写注册表；删除目录即卸载。

常用命令行参数
--------------
  tinycast.exe -addr :9000 -open     换端口并自动打开浏览器
  tinycast.exe -h                    查看全部参数
  tinysim.exe token -user bob -room 测试房   只打印一份推流配置
  tinysim.exe publish|unpublish|play|stop    单独发一次某个回调
  tinysim.exe state                  查询房间当前状态
  tinysim.exe demo -step 2s -viewers 5      调整演示节奏与观众数

登录令牌说明
------------
tinysim 每次运行如果没给 -token，会自己生成一个新的随机令牌。
同一个令牌只能绑定一个用户名，所以想看「用户名已被其它令牌占用」这类报错时，
请显式传 -token 复用它。
